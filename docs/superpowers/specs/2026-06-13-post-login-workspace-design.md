# 登录后知识工作台交互与视觉优化设计

日期：2026-06-13

## 1. 目标

优化登录后的聊天工作台，使知识库、收藏夹、视频与聊天之间的关系清晰可预测，并让整体视觉延续登录页的 Claude 风格。

本次设计同时覆盖桌面端与移动端，重点解决：

- 知识库选择位置抢占聊天视觉焦点。
- 收藏夹勾选同时承担多种含义，用户难以判断它影响入库还是聊天。
- 聊天无法真实限制到指定收藏夹或视频。
- 模型状态缺少清晰的厂商图标和延迟反馈。
- 初始聊天输入框过高。
- 登录页与登录后工作台的色彩、字体、圆角和层级不统一。
- 桌面侧栏状态、主题选择和移动端导航缺少稳定行为。

## 2. 设计原则

1. 聊天是登录后的主任务，知识管理作为清晰但克制的辅助层。
2. 知识库定义数据边界，收藏夹和视频可以进一步缩小本次对话范围。
3. “入库选择”和“提问范围”是两套独立状态，不复用同一组复选框。
4. 所有筛选必须由后端真实执行，不提供装饰性过滤。
5. 后端扩展保持向后兼容；不传新参数时，原有行为不变。
6. 深色和白天模式使用相同布局和状态语义，只替换视觉 Token。

## 3. 总体架构

采用“平衡工作台”：

- 聊天占据主内容区。
- 桌面端知识空间使用可开合侧栏。
- 平板和手机端知识空间使用全高左侧抽屉。
- 知识库选择器位于知识空间顶部，不在页面顶部居中展示。
- 页面顶部只保留品牌、主题切换和用户菜单。
- 模型状态位于聊天区右上角，保持紧凑。

### 3.1 前端组件边界

#### `Home`

负责：

- 系统登录态。
- 当前知识库 ID。
- 当前内容源绑定。
- 桌面侧栏和移动抽屉状态。
- 知识库切换时的跨组件状态清理。

不负责具体列表和聊天展示细节。

#### `WorkspaceHeader`

负责：

- 智库云品牌标识。
- 主题切换。
- 用户菜单。
- 移动端知识空间抽屉入口。

顶部不放大型知识库胶囊。

#### `KnowledgeWorkspace`

由现有 `KnowledgeBasePanel` 和 `SourcesPanel` 的职责重组而成，负责：

- 当前知识库选择、创建和删除。
- 展示当前知识库已入库视频总量。
- B 站绑定入口。
- 收藏夹列表、视频预览和入库状态。
- 入库任务选择、提交、进度和结果。

桌面端作为侧栏，移动端作为左侧抽屉，两种形态共享同一业务组件。

#### `ChatPanel`

负责：

- 模型状态和模型选择。
- 消息、来源、思考过程和消息操作。
- 独立的提问范围选择器。
- 紧凑且自动增长的输入区。

聊天组件不再接收“入库选择”的收藏夹状态。

## 4. 知识库交互

### 4.1 选择

知识库选择器固定在知识空间顶部，显示：

- 知识库名称。
- 已入库视频总数。
- 展开图标。

列表支持选择、创建和删除。删除仍使用现有后端能力。

### 4.2 切换行为

切换知识库时：

1. 清空当前聊天消息。
2. 清空当前提问范围，恢复为“整个知识库”。
3. 清空入库任务的收藏夹选择。
4. 清空与旧知识库有关的临时错误和提示。
5. 保留模型选择、主题和侧栏偏好。
6. 显示短暂提示：“已切换至 {知识库名称}”。

构建任务运行期间锁定知识库切换，避免任务目标与界面上下文不一致。

### 4.3 空状态

- 没有知识库：禁用聊天输入并引导创建。
- 知识库存在但无内容：提示选择收藏夹入库。
- 没有 B 站绑定：在知识空间显示绑定入口。

## 5. 收藏夹与入库交互

### 5.1 入库选择

收藏夹卡片上的复选框只表示：

> 将该收藏夹加入本次入库或更新任务。

它不改变聊天检索范围。

每张收藏夹卡片展示：

- 标题。
- 已入库数量 / 收藏夹有效视频数量。
- 最近同步时间。
- 状态：未入库、有更新、已入库。
- 展开视频列表入口。

### 5.2 卡片操作

- 点击复选框：改变本次入库任务选择。
- 点击卡片主体：展开或收起视频预览。
- 视频预览保留播放、打开 B 站链接和本地重命名能力。
- 可在展开列表中排除本次不希望入库的视频，沿用现有 `exclude_bvids` 请求能力。

### 5.3 底部任务栏

侧栏底部常驻任务栏，明确显示：

- 已选收藏夹数量。
- 预计新增或更新的视频数量；无法精确计算时显示已选视频总量。
- 目标知识库名称。
- 主操作文案，例如“更新 2 个收藏夹到产品学习库”。

### 5.4 构建状态

构建期间：

- 锁定知识库切换。
- 锁定本次任务的收藏夹和排除视频选择。
- 禁止重复提交。
- 允许展开收藏夹查看内容。
- 聊天继续使用任务开始前已完成入库的内容。
- 原位展示进度、当前步骤和处理数量。

完成后刷新知识库统计和收藏夹状态。失败时保留原选择并提供重试，不使用阻塞式全局弹窗。

## 6. 提问范围

### 6.1 默认范围

默认范围为：

> 当前知识库的全部已入库内容。

### 6.2 可选范围

用户可以在聊天输入区的“提问范围”选择器中组合选择：

- 多个已入库收藏夹。
- 多个已入库视频。

收藏夹与视频可以同时选择，最终允许的视频集合取并集。

未入库的收藏夹或视频不可作为提问范围，并显示“未入库”状态。

### 6.3 可见反馈

输入区持续显示当前范围：

- 整个知识库。
- 2 个收藏夹。
- 3 个视频。
- 2 个收藏夹 + 3 个视频。

范围摘要过长时只显示计数。用户可一键恢复“整个知识库”。

### 6.4 范围切换

改变提问范围时：

1. 清空当前消息并开启新对话。
2. 保留输入草稿。
3. 显示短暂提示，例如“提问范围已更新：2 个收藏夹 + 3 个视频”。

这样避免同一段对话中的回答来自不同资料范围。

## 7. 后端兼容扩展

用户已允许对后端做不破坏现有功能的最小扩展。

### 7.1 请求模型

为 scoped search/chat 请求增加可选字段：

```python
folder_ids: Optional[list[int]] = None  # B 站收藏夹 media_id
bvids: Optional[list[str]] = None
```

涉及：

- `POST /knowledge-bases/{id}/search`
- `POST /knowledge-bases/{id}/chat`
- `POST /knowledge-bases/{id}/chat/stream`

不传字段时，继续检索整个知识库。

新增只读接口：

- `GET /knowledge-bases/{id}/scope-options`

该接口返回当前知识库可用于提问范围的已同步收藏夹，以及每个收藏夹中可用的已入库视频。前端范围选择器只展示该接口返回的数据，不根据 B 站原始列表猜测视频是否已入库。

响应至少包含：

```json
{
  "folders": [
    {
      "media_id": 123,
      "title": "AI 课程",
      "video_count": 12,
      "videos": [
        {
          "bvid": "BV...",
          "title": "视频标题"
        }
      ]
    }
  ]
}
```

接口仅查询当前用户、当前工作区和当前知识库的数据，不修改任何状态。

### 7.2 所有权与范围校验

后端必须：

1. 验证知识库属于当前工作区。
2. 将 `folder_ids` 限制为当前知识库中已同步的收藏夹。
3. 将收藏夹解析为其中已入库的 BVID。
4. 将显式 `bvids` 限制为当前知识库中已入库的视频。
5. 对收藏夹 BVID 与显式 BVID 取并集。
6. 对越权或不存在的选择返回 `400`，不静默扩大检索范围。

空数组等同于未指定该字段；若用户明确选择范围但校验后集合为空，则返回 `400`，而不是回退到全库。

### 7.3 向量过滤

`search_in_knowledge_base` 扩展可选允许 BVID 集合。过滤条件始终包含：

```text
workspace_id = 当前工作区
AND knowledge_base_id = 当前知识库
AND bvid IN 允许集合（仅在指定范围时）
```

流式和非流式聊天使用相同的过滤解析逻辑。

## 8. 模型状态

聊天区右上角显示：

- 当前模型厂商图标。
- 厂商名称；移动端可省略名称。
- 健康状态点。
- 请求延迟，例如 `72 ms`。

点击后继续打开现有模型选择与配置菜单。

状态规则：

- 检查中：显示图标和“检查中”。
- 正常：绿色低饱和状态点和延迟。
- 异常：低饱和警示色，延迟替换为“不可用”。

## 9. 聊天输入区

初始状态使用单行紧凑高度：

- 空白或单行约 `52px`。
- 内容换行后按文本高度平滑增长。
- 桌面端最大约 `180px`。
- 手机端最大约 `150px`。
- 超过上限后输入框内部滚动。

输入区内包含：

- 文本输入。
- 提问范围入口和摘要。
- 智能检索、深度思考等现有开关。
- 发送或停止生成按钮。

## 10. 桌面与移动响应式

### 桌面端（宽度不小于 1024px）

- 知识空间侧栏默认展开。
- 用户可收起或拖动宽度。
- 记录侧栏开合状态和宽度。
- 新用户首次进入使用默认展开状态。

### 平板端（768px 至 1023px）

- 侧栏改为覆盖式左抽屉。
- 抽屉打开时遮罩聊天区。

### 手机端（小于 768px）

- 顶部菜单按钮打开全高左侧抽屉。
- 抽屉包含知识库和收藏夹完整功能。
- 聊天输入区位于底部安全区之上。
- 模型状态仅保留图标、状态点和延迟。

## 11. 视觉系统

### 11.1 深色模式

延续登录页：

- 页面背景：`#141413`
- 面板：`#262624`
- 控件：`#30302e`
- 主文字：`#faf9f5`
- 次文字：`#a8a49c`
- 陶土强调：`#d97757`
- 暖白主操作：`#f5f3ee`

### 11.2 白天模式

采用暖纸色，不使用纯白：

- 页面背景：`#f7f1e8` 到 `#efe1cf` 的轻渐变。
- 面板：半透明暖白。
- 侧栏：浅沙色。
- 主文字：深褐黑。
- 边框：低对比米棕色。
- 强调：沉稳陶土红。
- 成功状态：深青绿。

### 11.3 层级

- Serif 字体只用于品牌、空状态标题和重要标题。
- 工作区正文使用 Inter 和中文无衬线字体。
- 顶部不使用大型居中控件。
- 工作台圆角控制在 `12px` 至 `22px`，比登录页更紧凑。
- 阴影只用于抽屉、菜单和浮层；常驻面板主要依靠边框分层。

### 11.4 主题行为

- 首次进入默认深色。
- 用户可以切换深色或白天模式。
- 选择保存在本地并在下次访问恢复。
- 主题切换不改变布局和交互位置。

## 12. 错误处理

- 各接口错误在所属区域原位展示。
- 知识库加载失败：知识库区域提供重试。
- 收藏夹加载失败：收藏夹区域提供重试。
- 提问范围校验失败：范围选择器旁展示错误并阻止发送。
- 模型异常：模型状态控件展示“不可用”，聊天请求仍沿用现有错误处理。
- 构建失败：保留任务选择并提供重试。

## 13. 测试与验收

### 13.1 前端

- 登录态恢复和退出。
- 知识库创建、删除、切换与空状态。
- 切换知识库清空对话和范围。
- 桌面侧栏开合、拖动和本地记忆。
- 平板和手机左侧抽屉。
- 收藏夹展开、入库选择与视频排除。
- 构建期间锁定、进度、成功和失败重试。
- 模型厂商图标、健康状态和延迟。
- 输入框 `52px` 初始高度与自动增长。
- 多收藏夹、多视频和组合提问范围。
- 范围切换开启新对话。
- 深色和白天主题切换与记忆。

### 13.2 后端

- 不传过滤字段时与现有行为一致。
- 收藏夹只解析当前知识库中的已入库视频。
- 范围选项接口不返回其他知识库或未入库的视频。
- 显式 BVID 只能来自当前知识库。
- 越权、不存在或全部无效的显式范围返回 `400`。
- 收藏夹和视频组合取并集并去重。
- workspace、knowledge base 和 BVID 过滤同时生效。
- 搜索、流式聊天和非流式聊天范围一致。

## 14. 不改动范围

以下业务语义保持不变：

- 系统认证和 Cookie 会话。
- B 站账号绑定。
- 收藏夹获取和整理。
- 知识库构建任务的核心处理流程。
- 模型配置和切换。
- 回答生成、来源展示和现有消息操作。

除 scoped search/chat 的可选过滤参数和只读范围选项接口外，不新增后端业务模块。
