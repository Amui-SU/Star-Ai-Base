# 登录页桌面布局对齐设计

## 目标

修复桌面登录页中“没有账号？继续后即可创建”提示被挤到登录卡片右侧的问题，同时微调左侧视觉重心：左上品牌标识向左移动，登录主体略微上移。移动端现有布局保持不变。

## 根因

`.auth-form-section` 当前是横向 Flex 容器，`.auth-form-content` 与 `.auth-account-hint` 作为同级元素参与横向排列，因此提示文案出现在卡片右侧，而不是卡片下方。

## 设计

- 桌面端将 `.auth-form-section` 的主轴调整为纵向，使登录主体和账号提示按上下顺序排列。
- 账号提示继续保留在认证卡片之外，并在卡片下方居中，沿用现有间距变量。
- 桌面端通过局部位移将 `.auth-header-inner` 向左调整约 `16px`，不改变页面总体容器宽度。
- 桌面端将 `.auth-form-content` 与账号提示组成的整体向上调整约 `24px`，保持二者相对位置稳定。
- 在 `max-width: 1024px` 的现有响应式规则中清除桌面位移，避免影响平板和手机布局。

## 边界与兼容性

- 不改变登录流程、表单状态或第三方登录行为。
- 不调整右侧检索流程演示区域。
- 不改变移动端账号提示的底部绝对定位规则。
- 使用现有类名和 CSS 变量完成调整，不引入新组件或依赖。

## 验收标准

1. 桌面宽度下，账号提示位于登录卡片正下方且水平居中，不与右侧演示面板重叠。
2. 左上 Logo 相比当前布局向左移动约 `16px`。
3. 左侧标题、说明、登录卡片及账号提示作为整体向上移动约 `24px`。
4. `1024px` 及以下宽度保持现有移动端布局。
5. 登录页组件测试、前端构建和渲染检查通过，无新增控制台错误。

## 验证方案

- 为桌面布局类或结构补充回归断言，防止账号提示再次进入横向排列。
- 运行登录页相关 Vitest 测试与前端构建。
- 在桌面视口渲染登录页，检查提示位置、Logo 偏移和左侧主体高度；条件允许时再检查一个移动视口。
