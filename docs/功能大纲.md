# 项目功能大纲：Bilibili RAG（智库云·收藏夹知识库）

> 目标：把你在 B 站收藏的访谈/演讲/课程等内容，自动转成“可检索、可追溯来源、可对话”的个人知识库。

## 1. 项目定位与核心价值

- **一句话**：从 B 站收藏夹拉取视频 → 转写/提取文本 → 向量化入库 → 用 RAG 对话检索。
- **适用人群**：
  - 喜欢收藏学习视频但很难复盘的人
  - 需要把公开视频沉淀成“可查、可问、可引用”的资料库的人
  - 做知识整理/复习/内容回顾/会议分享复盘的人
- **核心卖点**：
  - 自动化流程：同步收藏夹、ASR 转写、向量检索、问答
  - “带来源”的回答：回答可附带相关视频标题与链接
  - 本地存储：SQLite + ChromaDB（向量）持久化

## 2. 功能清单（按用户视角）

### 2.1 登录与会话

**系统账号（多用户基础）**

- **注册**：邮箱 + 密码注册，自动创建个人工作区
- **登录/登出**：HttpOnly Secure Cookie 会话（14 天有效）
- **当前用户**：获取已登录用户信息

相关后端接口（`app/routers/system_auth.py`）：

- `POST /system-auth/register`
- `POST /system-auth/login`
- `POST /system-auth/logout`
- `GET /system-auth/me`

**B 站扫码登录（兼容旧流程）**

- **B 站扫码登录**：旧兼容身份入口，仅保留二维码、轮询确认状态与会话查询。
- **当前主流程**：登录后通过内容源绑定接入 B 站账号，不再依赖 `bili_session` 驱动工作台。

相关后端接口（`app/routers/auth.py`）：

- `GET /auth/qrcode`
- `GET /auth/qrcode/poll/{qrcode_key}`
- `GET /auth/session/{session_id}`
- `DELETE /auth/session/{session_id}`

### 2.2 内容源绑定（B 站账号）

- **B 站扫码绑定**：将 B 站账号作为内容源绑定到当前系统用户和工作区
- **绑定列表/撤销**：查看已绑定账号、撤销失效绑定
- **凭据加密**：B 站 Cookie 使用 Fernet 加密存储在 `source_credentials` 表

相关后端接口（`app/routers/source_bindings.py`）：

- `GET /source-bindings`
- `DELETE /source-bindings/{binding_id}`
- `GET /source-bindings/bilibili/qrcode`
- `GET /source-bindings/bilibili/qrcode/poll/{qrcode_key}`

### 2.3 知识库管理（多用户）

- **创建/列表**：按当前工作区创建和查看知识库
- **范围化检索**：语义搜索只返回当前知识库内的片段
- **范围化问答**：基于当前知识库内容的 RAG 问答（非流式 + 流式）
- **范围化构建**：从已绑定的内容源入库到指定知识库
- **所有权校验**：所有操作校验当前用户 → 工作区 → 知识库归属

相关后端接口（`app/routers/knowledge_bases.py`）：

- `GET /knowledge-bases`
- `POST /knowledge-bases`
- `GET /knowledge-bases/{id}/stats`
- `GET /knowledge-bases/{id}/scope-options`
- `POST /knowledge-bases/{id}/search`
- `POST /knowledge-bases/{id}/chat`
- `POST /knowledge-bases/{id}/chat/stream`
- `POST /knowledge-bases/{id}/build`
- `GET /knowledge-bases/{id}/build/status/{task_id}`
- `DELETE /knowledge-bases/{id}`

### 2.4 收藏夹管理（同步前的”选源”）

- **拉取收藏夹列表**：展示收藏夹标题、视频数量。
- **展开查看视频列表**：获取收藏夹全部视频（用于用户预览与数量校准）。
- **默认收藏夹快速整理（可选）**：
  - 支持对默认收藏夹进行“整理预览”与“执行移动”（后端已提供接口；前端提供入口按钮与弹窗）。

相关后端接口（`app/routers/favorites.py`）：

- `GET /favorites/list?session_id=...`
- `GET /favorites/{media_id}/videos?session_id=...&page=...`
- `GET /favorites/{media_id}/all-videos?session_id=...`
- `POST /favorites/organize/preview?session_id=...`
- `POST /favorites/organize/execute?session_id=...`
- `POST /favorites/organize/clean-invalid?session_id=...`

### 2.5 旧全局知识库/RAG 入口（已禁用）

- `/knowledge/*` 和 `/chat/ask|ask/stream|search` 属于未隔离的旧全局能力，已统一返回 `410 Gone`。
- 产品主流程必须使用 `/knowledge-bases/{id}/*` scoped API，以系统登录态和当前工作区/知识库归属作为边界。
- 旧 `app/routers/knowledge.py` 中仍保留少量 legacy/诊断辅助代码，但不作为产品入口。

已禁用接口（统一提示迁移到 `/knowledge-bases/*`）：

- `GET /knowledge/stats`
- `GET /knowledge/folders/status?session_id=...`
- `POST /knowledge/folders/sync?session_id=...`
- `POST /knowledge/build?session_id=...`
- `GET /knowledge/build/status/{task_id}`
- `DELETE /knowledge/clear`
- `DELETE /knowledge/video/{bvid}`
- `POST /chat/ask`
- `POST /chat/ask/stream`
- `POST /chat/search?query=...&k=...`

### 2.6 问答与检索（scoped RAG）

- **问答**：输入问题，系统基于当前知识库已入库内容回答；可返回关联视频来源列表。
- **流式问答**：前端优先调用当前知识库的流式接口，失败时自动回退到同一 scoped 非流式接口。
- **语义检索**：支持在当前知识库内检索相关片段。
- **提问范围**：可选择整个知识库、多个收藏夹或多个视频；后端校验 `folder_ids/bvids` 属于当前知识库后再应用向量过滤。

相关后端接口（`app/routers/knowledge_bases.py`）：

- `POST /knowledge-bases/{id}/chat`
- `POST /knowledge-bases/{id}/chat/stream`
- `POST /knowledge-bases/{id}/search`
- `GET /knowledge-bases/{id}/scope-options`

## 3. 核心流程（端到端）

### 3.1 首次使用

1. 注册/登录系统账号，进入个人工作区
2. 绑定 B 站内容源并拉取收藏夹列表
3. 创建或选择知识库，勾选要入库的收藏夹 → 点击“入库”
4. 后端开始构建任务：
   - 拉取收藏夹内所有视频
   - 对每个视频获取内容（优先 ASR，失败再兜底基础信息）
   - 切分文本 → Embedding → 写入 Chroma
   - 同步状态写入 SQLite
5. 在当前知识库对话区提问，得到“回答 + 来源视频”

### 3.2 日常增量更新

1. 刷新收藏夹状态
2. 选中已有收藏夹 → 点击“更新”
3. 系统会识别新增/需要更新的视频重新入库并更新向量

## 4. 架构与模块划分（按代码结构）

### 4.1 后端（FastAPI）

入口：`app/main.py`

- **路由层（`app/routers/`）**
  - `system_auth.py`：系统用户注册/登录/登出/当前用户（HttpOnly Cookie 会话）
  - `source_bindings.py`：B 站账号绑定/撤销/QR 流程（凭据加密存储）
  - `knowledge_bases.py`：多用户知识库 CRUD + scoped search/chat/chat-stream/build
  - `auth.py`：B 站扫码登录、会话创建/查询/注销（旧兼容入口）
  - `favorites.py`：收藏夹/视频列表读取；默认收藏夹整理（预览/执行/清理失效）
  - `knowledge.py`：同步/构建/任务状态；入库统计；清库/删视频（旧 B 站 session 驱动）
  - `chat.py`：问答、检索、流式输出；问题路由（direct/db_list/db_content/vector）；LLM 提供方切换

- **服务层（`app/services/`）**
  - `bilibili.py`：封装 B 站相关调用（二维码、收藏夹、视频信息、音频地址与下载等）
  - `wbi.py`：WBI 签名/鉴权相关逻辑（用于部分 B 站接口）
  - `asr.py`：ASR 服务（DashScope），支持 URL 转写与本地文件上传转写
  - `content_fetcher.py`：内容获取与降级策略（优先 ASR；音频 403 时本地下载+转码+上传识别；最终兜底基础信息）
  - `rag.py`：向量库与 RAG 问答（Chroma + Embeddings + LLM），提供检索、入库、问答与统计；新写入带 workspace/knowledge_base 元数据，scoped 检索强制 $and 过滤

- **数据与安全层**
  - `app/database.py`：Async SQLAlchemy 初始化与 session 管理
  - `app/models.py`：ORM 模型（SystemUser, Workspace, KnowledgeBase, SourceBinding 等）+ Pydantic 请求/响应模型
  - `app/dependencies.py`：FastAPI 依赖注入（get_current_user → get_current_workspace → get_knowledge_base_for_user）
  - `app/security.py`：bcrypt 密码哈希、SHA-256 session token、Fernet 凭据加密
  - 持久化：
    - SQLite：`./data/bilibili_rag.db`（默认）
    - Chroma：`./data/chroma_db/`（默认）

### 4.2 前端（Next.js App Router）

入口页面：`frontend/app/page.tsx`

- **页面结构（用户所见）**
  - 未登录：展示产品介绍、登录按钮、演示流程入口
  - 已登录：主工作台（侧边栏 + 对话区）

- **主要组件（`frontend/components/`）**
  - `AuthPage.tsx`：系统登录/注册页面，内嵌检索流程动画
  - `KnowledgeBasePanel.tsx`：知识库创建、选择、删除与当前统计展示
  - `SourcesPanel.tsx`：收藏夹列表、展开视频、入库/更新按钮、构建进度条、快速整理入口
  - `ChatPanel.tsx`：对话与消息渲染、scoped 流式问答、来源链接、模型状态与提问范围

## 5. 关键能力说明（实现要点）

### 5.1 内容来源与降级策略

`app/services/content_fetcher.py` 采用“分层兜底”策略：

1. **ASR（优先）**：从音频提取文本
2. **音频不可达兜底**：直链拉取失败（常见 403）时，本地带 Cookie 下载音频 → `ffmpeg` 转码/切分 → 上传到 ASR 识别
3. **基础信息兜底**：至少保证“标题 + 简介”可入库，避免全空

### 5.2 RAG 与回答来源

`app/services/rag.py`：

- 文本切分：`chunk_size=1000, chunk_overlap=200`
- 向量库：Chroma（持久化目录由 `CHROMA_PERSIST_DIRECTORY` 控制）
- Embedding：优先 `DashScopeEmbeddings`，不可用则退到 `OpenAIEmbeddings`
- 回答：检索 top-k 文档块 → 拼接上下文 → LLM 生成回答
- 多用户隔离：新写入向量带 `workspace_id` / `knowledge_base_id` / `source_binding_id` 元数据；`search_in_knowledge_base()` 强制 $and 过滤

### 5.3 多用户数据隔离

- **三层校验链**：`get_current_user` → `get_current_workspace` → `get_knowledge_base_for_user`
- **知识库归属**：所有 scoped 接口校验知识库属于当前工作区
- **内容源绑定归属**：B 站绑定属于当前用户和当前工作区，凭据 Fernet 加密存储
- **缓存隔离**：`VideoCache` 按 `workspace_id + knowledge_base_id + source_binding_id + bvid` 作用域保存，同一 `bvid` 在不同知识库互不覆盖
- **Chroma 向量过滤**：scoped 检索强制 `{"$and": [{"workspace_id": ...}, {"knowledge_base_id": ...}]}`，指定视频范围时追加 `bvid IN (...)`
- **向量删除隔离**：重建、URL 导入和删除知识库只删除当前知识库 metadata 命中的向量

`app/routers/chat.py`：

- 有一套问题路由策略：
  - `direct`：闲聊/与收藏无关
  - `db_list`：清单类（只用标题/简介作答）
  - `db_content`：全库总结类
  - `vector`：具体主题问题（走向量检索）

## 7. 约束、风险与常见问题（FAQ 简版）

- **音频直链 403**：属于平台鉴权/过期等问题，系统会自动走“本地下载 + 上传识别”的兜底流程；请确保 `ffmpeg` 可用。
- **费用**：LLM/Embedding/ASR 通常是按量计费（token/时长）。建议先用短视频测试。
- **隐私与合规**：项目定位为个人学习与技术研究，请自行遵守平台协议与法律法规。
