# 移动端发布检查清单

用于每次打包或外发 `移动端.apk` 前做固定验证，减少“本机能跑，换设备连不上”的问题。

## 1. 配置检查

- [ ] 仓库根目录存在 `.env.example`。
- [ ] 本机真实配置写在 `.env.local` 或系统环境变量中。
- [ ] `.env.local` 没有准备提交到 git。
- [ ] `DASHSCOPE_API_KEY` 或当前使用模型的 API Key 已配置。
- [ ] 本地视频导入需要 ASR 时，DashScope ASR 相关配置已配置。
- [ ] `DEBUG=false` 时已配置 `APP_ENCRYPTION_KEY`。
- [ ] 需要邮件验证码时，`SMTP_HOST`、`SMTP_USER`、`SMTP_PASSWORD`、`SMTP_FROM` 已配置。
- [ ] 生产外发时，网关限流或反向代理限流已覆盖 `POST /system-auth/send-code`，按真实客户端 IP 做 per-IP 限制，并向后端保留可信 `X-Forwarded-For`。
- [ ] 需要 OAuth 登录时，对应 provider 的 client id、client secret、redirect uri 已配置。

## 2. 本机服务检查

在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\dev.ps1 doctor
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\dev.ps1 status
```

发布前应确认：

- [ ] Python、Node.js、npm 检测通过。
- [ ] 后端依赖健康。
- [ ] 前端依赖已安装。
- [ ] ffmpeg 可用。
- [ ] `logs/` 可写。
- [ ] 后端运行在 `0.0.0.0:8000` 或计划使用的局域网端口。
- [ ] 前端运行在 `3000`，或静态 APK 已内置最新 `out/` 资源。

## 3. 网络连接检查

- [ ] 电脑和手机处于同一 Wi-Fi 或可互通局域网。
- [ ] Windows 防火墙或安全软件未拦截后端端口。
- [ ] VPN、代理、TUN 模式没有阻断局域网访问。
- [ ] 电脑端用户菜单能显示 `电脑局域网地址`。
- [ ] 手机浏览器可打开：

```text
http://<电脑局域网 IP>:8000/health
```

期望返回：

```json
{ "status": "healthy" }
```

## 4. 自动化验证

后端：

```powershell
python -m pytest
```

前端：

```powershell
cd frontend
npm test
npm run lint
npm run build
```

发布前应确认：

- [ ] 后端 pytest 全部通过。
- [ ] 前端 Vitest 全部通过。
- [ ] ESLint 不扫描 Android/Gradle 生成产物。
- [ ] Next.js 静态导出成功。

## 5. APK 构建前检查

在 `frontend` 目录执行生产构建后，再同步 Capacitor：

```powershell
npm run build
npx cap sync android
```

发布前应确认：

- [ ] `frontend/out/` 是最新构建。
- [ ] `frontend/android/app/src/main/assets/public/` 已同步最新静态资源。
- [ ] 未把 Android build 输出、Gradle 缓存或本机 SDK 路径提交到 git。

## 6. 真机冒烟测试

安装 APK 后，在真机完成以下路径：

- [ ] 首次打开后出现连接设置。
- [ ] 扫描电脑端二维码并保存后端地址。
- [ ] 连接保存提示正常出现。
- [ ] 登录或注册系统账号。
- [ ] 创建或选择知识库。
- [ ] 绑定 B 站内容源。
- [ ] 展开收藏夹列表。
- [ ] 导入一条短视频或小收藏夹。
- [ ] 入库任务状态能从 pending/running 进入 completed，失败时能看到原因。
- [ ] 在当前知识库提问，回答和来源链接正常展示。
- [ ] 侧栏展开/收起正常。
- [ ] 暗色/亮色主题切换正常。
- [ ] 后端停止时，移动端能显示可理解的连接错误。

## 7. 发布物检查

- [ ] APK 文件名包含日期或版本号。
- [ ] README 中的使用说明与当前 APK 行为一致。
- [ ] 已记录本次发布使用的后端 commit、前端 commit、构建时间。
- [ ] 已记录已知问题和回滚方式。
